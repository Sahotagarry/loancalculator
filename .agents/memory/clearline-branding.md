---
name: Clearline branding
description: Clearline is the full-service CPA firm, not this app — never imply the app is all Clearline does
---

Rule: "Clearline" refers to the user's full-service CPA firm. This loan/lease calculator is just one internal engagement tool. In UI copy and help text, never say "Clearline does/builds X" about app features — say "this application" or "the Clearline Loan Calculator".

**Why:** user corrected help copy that read "Clearline builds ASPE-compliant loan and lease amortization tables…" — "as if this is all we do."

**How to apply:** when writing any user-facing copy (help topics, welcome screens, descriptions), attribute functionality to the app/tool, not to Clearline the firm.
